Sixteen statuses, the same ones the order file uses. Ticking the last check of a step in block 03 moves the matching order along here.

The order board is one row per order. This is one row per SKU — how many pieces an account is still owed. Anything carried three months or more is flagged. Clearing the ledger archives a monthly snapshot; it never deletes.
